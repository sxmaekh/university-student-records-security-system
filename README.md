# university-student-records-security-system

## Project Overview
This project develops a secure university student records
database using PostgreSQL 18 and pgAdmin 4.

## Project Phases
1. Database Design and Setup
2. Roles, Permissions, and Row-Level Security
3. Database Auditing
4. Performance Optimization
5. Backup and Recovery
6. Monitoring and Final Testing

## Technologies
- PostgreSQL 18
- pgAdmin 4
- SQL
- GitHub
